# Exploratory Data Analysis of Theoph Pharmacokinetic Dataset

## Overview
This project presents an Exploratory Data Analysis (EDA) of the Theoph dataset, a classical pharmacokinetic dataset available in R. The dataset contains measurements of theophylline concentration in blood over time for multiple subjects following oral administration.

## Objectives
- Understand the structure of pharmacokinetic data
- Explore concentration-time relationships
- Analyze variability across subjects
- Visualize pharmacokinetic trends using R

## Dataset
The Theoph dataset includes:
- Subject ID
- Time after dose administration
- Drug concentration
- Dose amount
- Subject weight

## Tools Used
- R
- ggplot2
- dplyr

## Analysis Performed
- Explored dataset structure and variables
- Generated summary statistics
- Examined the distribution of concentration values
- Visualized concentration versus time relationships
- Compared concentration profiles across subjects
- Identified overall pharmacokinetic patterns

## Key Findings
- Drug concentration changes significantly over time after administration.
- Noticeable variability exists among subjects.
- Concentration-time profiles demonstrate characteristic absorption and elimination phases.
