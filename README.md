Exploratory Data Analysis of Theoph Pharmacokinetic Dataset
Overview

This project presents an exploratory data analysis (EDA) of the Theoph dataset, a classical pharmacokinetic dataset available in R. The dataset contains measurements of theophylline concentration in blood over time for multiple subjects after oral drug administration.

Objectives
Understand the structure of pharmacokinetic data
Explore concentration-time relationships
Analyze variability across subjects
Visualize pharmacokinetic trends using R
Dataset

The Theoph dataset is included in R and contains:

Subject ID
Time after dose administration
Drug concentration
Dose amount
Subject weight
Tools Used
R
ggplot2
dplyr
Analysis Performed
Dataset exploration and structure inspection
Summary statistics of pharmacokinetic variables
Distribution analysis of concentration measurements
Concentration vs. time visualizations
Subject-wise concentration profile analysis
Identification of overall pharmacokinetic trends
Key Findings
Drug concentration changes significantly over time following administration.
Individual subjects exhibit different concentration-time profiles.
Visualizations highlight characteristic absorption and elimination phases of theophylline.
